# Engram agent bootstrap files

This ZIP contains current-state agent files for the Engram redesign branch.

It includes:

- `AGENTS.md` — active root project instruction file.
- `.codex/skills/*/SKILL.md` — active Codex skill files.
- `agent-files/*` — inactive templates with names that should not be auto-loaded.

The skill content intentionally references only tools that exist in the current redesign branch. After the simplified workflow is implemented, update these files to use the new tool names and simplified memory/task lifecycle.
